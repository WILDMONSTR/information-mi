## 평가 범위 및 한계

- 코드 보존 기준 커밋: `bdb3e0954bc32dc4f8e6681ab6d82f4ce5cd7388`
- 두 환경(Node.js 24.20.0 및 20.20.0)의 기록상 T05-C01~C10은 모두 PASS.
- 두 실행 모두 합성 업스트림 응답을 사용하는 테스트이므로 실제 API 호출이나 배포를 증명하지 않는다.
- 실제 작업시간·전체 요청/호출 수, 원래 AI B 세션 입력물의 독립 확인은 미입증이며 추측하지 않는다.
- 비교표는 AI A/AI B로만 표기한다. 서비스·모델명은 표에 넣지 않았다.
- 로컬 사용자 프로필 경로는 제출용 문서에서 일반화했다.

## 다음 작업의 도구 선택 기준

- 정확도와 중요도가 높은 작업은 **AI B(후보 Y)**를 우선 선택한다.
- 중요도는 상대적으로 낮지만 처리량이 많은 작업은 **AI A(후보 X)**를 선택한다.
- 이번 작업에서 관찰한 AI A의 지시·브랜치 경계 준수 문제, 인수인계 문서 보완 필요, 무료 토큰 소진 후 다른 후보로의 전환 불편을 고려한 실무 기준이다. 근거와 단서는 [비식별 비교표의 C29 항목](./T05_AI_AB_비식별_비교표_20261015.md#다음-작업의-도구-선택-기준-c29)에 기록했다. 이는 두 후보의 모든 상황에서의 성능을 독립적으로 입증했다는 주장은 아니다.
