## 반드시 지킬 것

1. 과거 AI A 실행 기록을 AI B의 결과로 복사하지 않는다.
2. 독립된 새 폴더에서 저장소를 가져오고, 지정 커밋과 Node 버전을 실제 출력으로 확인한다.
3. `node --check index.js`, `node --check public/js/market.js`, `node test-marketPrices.js`를 실행한다.
4. 각 명령의 실제 출력과 종료 코드를 보존한다. T05-C01~C10이 모두 PASS인지 각각 확인한다.
5. 최종 `git status --short`, 기준 대비 diff, 로그 파일과 SHA-256을 기록한다.
6. 버전/커밋 불일치, 네트워크 오류 또는 실행 제한이 있으면 중단 사유를 기록한다. 실행하지 않은 검사는 PASS로 쓰지 않는다.
7. 테스트 코드, 기능 코드, 의존성, 원격 브랜치를 수정하지 않는다. Firebase 배포나 실제 API 호출을 하지 않는다.
8. 최종 보고서에 인수인계 7항목 확인표, 실행 환경, 명령, 검사 결과, 미해결 문제, 다음 행동, 금지한 변경을 포함한다.

## 비교의 공정성

AI A의 이번 실행은 GitHub 복제 시 DNS 오류로 막혀 테스트를 실행하지 못했다. 이를 숨기거나 점수로 바꾸지 말고, AI B의 결과도 별도로 기록하라. AI B만 실행에 성공하더라도 그것만으로 AI A/B 성능 우위를 판정하지 않는다. 유효한 비교는 양쪽 모두 같은 버전·커밋·검사·제약을 사용한 결과가 확보된 뒤에만 가능하다.

테스트는 합성 업스트림 응답을 사용하므로 실제 MobiLife API 연동이나 Firebase 배포가 검증되는 것은 아니다.
